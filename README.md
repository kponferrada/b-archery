# Jamie's Crossbows (Project Zomboid B42.21)

Ten glowing crossbows that shoot real bolts. Standalone mod (split out of Jamie's Treasures 0.11.6).

* `Contents/mods/JamiesCrossbowsWIP` - the mod (WIP id `JamiesCrossbowsWIP`)
* `dev/build.py` - builds meshes, textures, icons, sounds and scripts from `dev/catalog.py` and `dev/art/crossbows.py`
* `dev/tests/run_all.sh [<game media>]` - offline checks (lint, script checks, Lua tests)
* hand-made: `42/media/lua` (except `JC_Catalog.lua`), `shaders/`, `AnimSets/`, `sandbox-options.txt`, `mod.info`
